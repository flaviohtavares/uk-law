## SCHEDULE 4 — Registration of a voluntary return point operator: Information to be contained in an application for registration

*Extent: S*

Regulation 25(2)(b)

**1.**[^c-95f314e463657c6594875c057674b6a2] The name (including business name), of the person who will be the return point operator.

**2.**[^c-c6a522e82dba44962cbff06f2fbd8dd3] The address and telephone number of the registered or principal office of that operator.

**3.**[^c-183539f622fc9163cf2e908c5c4d07e3] The address and telephone number of the proposed return point if different from that in paragraph 2.

**4.**[^c-f5adbe6d497e9d7849b4eea6d507012c] Information about the accessibility of the proposed return point including—

- (a) the physical location of it,
- (b) routes of access to it, and
- (c) its proposed hours of operation.

**5.**[^c-a44f5d7a31143efaa3c5705da5cbf14d] Information which demonstrates—

- (a) that the applicant has sufficient resources to set up and operate the return point for the first year of operation,
- (b) the number of items of scheme packaging the applicant expects to be returned to them in an average month and how this has been calculated,
- (c) how the applicant intends to manage this volume of returns.

**6.**[^c-9463ed44d78036e230dbcc7b7b4f8f50] Whether the applicant intends, in relation to a single proposed return by a consumer that contains a number of items of scheme packaging or returnable packaging, to impose a limit on the maximum number of items of scheme packaging or returnable packaging that the applicant will accept as part of a single return in accordance with regulation 20(4)(h), and if the applicant does so intend, what that limit is.
