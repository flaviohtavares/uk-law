# The Insolvency Rules (Northern Ireland) 1991, section 7.06

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

## 7.06. Interpretation

(1) In this Chapter, except in so far as the context otherwise requires—

- “**originating application**” means an application to the court which is not an application in pending proceedings before the court; and[^m00239]
- “**ordinary application**” means any other application to the court.[^m00240]

(2) Every application shall be in the form appropriate to the application concerned.
