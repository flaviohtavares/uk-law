# The Building Society Insolvency Rules (Northern Ireland) 2014, section 274

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

## 274. Introductory

This Part of the Rules has effect for their interpretation and application; and any definition given in this Part (and in any provision of the 1991 Rules applied by this Part) applies except, and in so far as, the context requires otherwise.
