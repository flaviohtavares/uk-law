# The Building Society Insolvency Rules (Northern Ireland) 2014, section 51

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

## 51. Resolutions

(1) Apply rule 4.070 of the 1991 Rules.

(2) In paragraph (2) for “the number of votes conferred on each contributory by the company’s articles” substitute “the value of the shares each contributory holds in the society”.
