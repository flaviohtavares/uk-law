# The Building Society Insolvency Rules (Northern Ireland) 2014, section 260

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

## 260. Time

Apply rule 12.10 of the 1991 Rules as regards time for anything required or authorised to be done by these Rules.
