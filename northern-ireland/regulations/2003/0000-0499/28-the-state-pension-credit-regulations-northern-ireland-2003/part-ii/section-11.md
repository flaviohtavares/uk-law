# The State Pension Credit Regulations (Northern Ireland) 2003, section 11

## 11. Retirement provision in assessed income period[^c-c54f4e4e721b91aebdfd4d3f5c069ba4]

*Extent: N.I.*

(1)[^c-ce54fa74697e6f38b8f9dc928e21e180] Where an element of a person’s retirement provision ceases to be payable by one source but –

- (a) responsibility for that element is assumed by another source, income from both those sources shall be treated as income from the same source, or
- (b) in consequence of that element ceasing, income of a different description becomes payable from a different source, that income shall be treated as income of the same description from the same source as the element which ceased to be payable.

(2)[^c-c5c73ad71f59814c13b77f8eae1c800a] For the purposes of section 7(6) of the Act, a foreign state retirement pension is to be treated as a benefit under the Contributions and Benefits Act.
