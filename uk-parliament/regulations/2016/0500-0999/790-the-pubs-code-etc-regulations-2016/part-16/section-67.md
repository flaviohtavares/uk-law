# The Pubs Code etc. Regulations 2016, section 67

> Text as at 2022-04-01.
>
> Extent: England, Wales.

## 67. Market rent only option: the MRO notice[^c-68a35043ea5a88fe0e939b65ed99baef]

*Extent: E+W*

(1) References in regulation 23(1) to an event occurring do not include an event which occurred before the commencement date.

(2) The reference in regulation 25(1) to a relevant analysis which demonstrates that a trigger event has occurred does not include a relevant analysis which demonstrates that a trigger event has occurred before the commencement date.
