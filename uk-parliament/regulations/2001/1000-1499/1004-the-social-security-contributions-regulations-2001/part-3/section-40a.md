# The Social Security (Contributions) Regulations 2001, section 40A

> Text as at 2026-07-20.
>
> Extent: England, Wales, Scotland, Northern Ireland.

## 40A. Exception from liability to pay Class 1A contributions in respect of an amount representing an amount on which Class 1 or Class 1A contributions have already been paid pursuant to the Social Security Contributions (Limited Liability Partnership) Regulations 2014[^c-c3d13b57a27f058c4b31069f3000d85d]

*Extent: E+W+S+N.I.*

Class 1A contributions shall not be payable in respect of a benefit in kind provided by an employer to an employed earner which represents an amount on which Class 1 or Class 1A contributions are payable by a limited liability partnership in respect of that earner by virtue of regulation 3 or 4 of the Social Security Contributions (Limited Liability Partnership) Regulations 2014.
