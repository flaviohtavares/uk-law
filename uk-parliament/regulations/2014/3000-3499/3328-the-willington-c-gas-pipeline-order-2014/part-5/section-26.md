# The Willington C Gas Pipeline Order 2014, section 26

> Text as at 2017-12-28.
>
> Extent: England, Wales, Scotland.

## 26. No double recovery[^key-44e64b82ea7d33722686a788723cbfdc]

*Extent: E+W+S*

Compensation is not payable in respect of the same matter both under this Order and under any other enactment, any contract or any rule of law.
