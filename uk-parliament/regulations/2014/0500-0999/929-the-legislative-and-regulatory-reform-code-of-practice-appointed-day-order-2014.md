# The Legislative and Regulatory Reform Code of Practice (Appointed Day) Order 2014

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

2014 No. 929 (C. 41)

Regulatory Reform

The Legislative and Regulatory Reform Code of Practice (Appointed Day) Order 2014

Made

25th March 2014

This Order is made in exercise of the powers conferred by section 23(6) of the Legislative and Regulatory Reform Act 2006[^f00001] (“the Act”).

In accordance with section 23 of the Act—

- (a) The Secretary of State has consulted persons appearing to him to be representative of persons exercising regulatory functions and such other persons as he considered appropriate about the draft code of practice;
- (b) the Secretary of State laid the draft code of practice before Parliament on 22 January 2014;
- (c) each House of Parliament approved by resolution the draft code of practice.

A draft of this instrument has been approved by a resolution of each House of Parliament pursuant to section 23(4) of the Act.

In accordance with section 22(1) of the Act, the Secretary of State issued the Code of Practice entitled the Regulators’ Code on 13 March 2014.

## 1. Citation

This Order may be cited as the Legislative and Regulatory Reform Code of Practice (Appointed Day) Order 2014.

## 2. Appointed Day

The day appointed for the coming into force of the Code of Practice entitled the Regulator’s Code is 6 April 2014.

Michael Fallon

Minister of State for Business and Energy

Department for Business, Innovation and Skills

25th March 2014

EXPLANATORY NOTE

(This note is not part of the Order)

This Order appoints 6 April 2014 for the coming into force of the Regulators’ Code. The Regulators’ Code was issued by the Secretary of State on 13 March 2014 under section 22(1) of the Legislative and Regulatory Reform Act 2006 (“the Act”).

Section 22 of the Act enables a Minister of the Crown to issue a code of practice relating to the exercise of regulatory functions. This section imposes a duty on any person exercising a specified regulatory function to have regard to the Regulators’ Code when determining general policies or principles by reference to which that person exercises those functions. It also applies to any person exercising a regulatory function of setting standards or giving guidance about the exercise of other regulatory functions (whether their own or someone else’s functions).

The regulatory functions to which section 22 applies are those specified by order under section 24(2) of the Act.

The Regulators’ Code replaces the Regulators’ Compliance Code which came into force on 6 April 2008.

Copies of the Regulators’ Code can be downloaded free of charge from the www.gov.uk website.
