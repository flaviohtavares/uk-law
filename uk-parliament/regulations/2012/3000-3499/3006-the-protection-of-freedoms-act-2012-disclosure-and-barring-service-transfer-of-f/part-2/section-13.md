# The Protection of Freedoms Act 2012 (Disclosure and Barring Service Transfer of Functions) Order 2012, section 13

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

## 13. Consequential amendments to other enactments

(1) For the words in the left-hand column of the table, wherever they appear in the provisions of the Acts of Parliament mentioned in paragraph (2) or the subordinate legislation mentioned in paragraph (3), substitute the corresponding words in the right-hand column of the table.

| Existing words | Substitution |
| --- | --- |
|  |  |
| “Independent Barring Board” | “Disclosure and Barring Service” |
| “IBB” | “DBS” |
| “Independent Safeguarding Authority” | “Disclosure and Barring Service” |
| “ISA” | “DBS” |
| “the Authority” | “the Service” |
| “the Board” | “the Service” |
|  |  |
|  |  |
|  |  |
