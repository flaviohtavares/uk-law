# The Human Medicines Regulations 2012, section 50F

> **Warning: changes not yet applied to this text (9).** Text as at 2026-03-31. See https://www.legislation.gov.uk/changes/affected/uksi/2012/1916

## 50F. Other applications including paediatric indications[^c-52e839230fb362e2a135f4458db34b5e]

*Extent: E+W+S+N.I.*

(1) This regulation applies in relation to an application to which neither regulation 50A nor 50E applies and which is—

- (a) an application for a UKMA(UK)(Category 1)[^c-27fd7d367283ec1500c71006e3d06be8] for a relevant medicinal product which includes a paediatric indication; or
- (b) an application to include a paediatric indication in an existing UKMA(GB) or a UKMA(UK)(Category 1)[^c-41b1c98156041040d9cfd1c19f95c5aa].

(2) The applicant making an application to which this regulation applies must include in the application details of the measures intended to ensure the follow up of efficacy and of possible adverse reactions to the paediatric use of the medicinal product.
