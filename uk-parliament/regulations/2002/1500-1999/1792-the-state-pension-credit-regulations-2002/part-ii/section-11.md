# The State Pension Credit Regulations 2002, section 11

> **Warning: changes not yet applied to this text (13).** Text as at 2026-07-16. See https://www.legislation.gov.uk/changes/affected/uksi/2002/1792

## 11. Retirement provision in assessed income period

(1)[^key-775ee792ad5f3ee6dc44e277b30fd344] Where an element of a person’s retirement provision ceases to be payable by one source but—

- (a) responsibility for that element is assumed by another source, income from both those sources shall be treated as income from the same source; or
- (b) in consequence of that element ceasing, income of a different description becomes payable from a different source, that income shall be treated as income of the same description from the same source as the element which ceased to be payable.

(2)[^key-ed40a8dbc1f61951bab608dbfe6df263] For the purposes of section 7(6) (meaning of retirement provision) of the Act, a foreign state retirement pension is to be treated as a benefit under the 1992 Act.
