# The Railways (Interoperability) (High-Speed) Regulations 2002, section 23

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

## 23. Interoperability constituents: duties on operators

The operator of any interoperability constituent that is in use on, or is part of, a rail network scheme, shall ensure that while it is so in use it is—

- (a) correctly installed for the purpose for which it is intended to be used;
- (b) not used for any purpose other than the purpose for which it was designed; and
- (c) maintained in an efficient state, effective working order and good repair.
