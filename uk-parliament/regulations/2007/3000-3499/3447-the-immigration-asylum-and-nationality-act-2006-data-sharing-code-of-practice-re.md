# The Immigration, Asylum and Nationality Act 2006 (Data Sharing Code of Practice) (Revocation) Order 2007

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

This Order revokes the Immigration, Asylum and Nationality Act 2006 (Data Sharing Code of Practice) Order 2007, which has not been published, and is being issued free of charge.

The Secretary of State and the Treasury make the following Order in exercise of the powers conferred by section 37(2) of the Immigration, Asylum and Nationality Act 2006[^f00001].

## 1. Citation and commencement

This Order may be cited as the Immigration, Asylum and Nationality Act 2006 (Data Sharing Code of Practice) (Revocation) Order 2007 and shall come into force on 31st December 2007.

## 2. Revocation

The Immigration, Asylum and Nationality Act 2006 (Data Sharing Code of Practice) Order 2007[^f00002] is revoked.

EXPLANATORY NOTE

(This note is not part of the Order)

This Order revokes the Immigration, Asylum and Nationality Act 2006 (Data Sharing Code of Practice) Order 2007 (“the Code of Practice Order”) and comes into force on 31st December 2007 (the date on which the Code of Practice Order would have come into force had it not been revoked).
