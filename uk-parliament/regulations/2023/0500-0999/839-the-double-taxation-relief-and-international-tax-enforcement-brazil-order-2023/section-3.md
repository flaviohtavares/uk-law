# The Double Taxation Relief and International Tax Enforcement (Brazil) Order 2023, section 3

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

## 3. Revocation and transitional provisions

(1) The Double Taxation Relief (Shipping and Air Transport Profits) (Brazil) Order 1968[^f00003] is revoked.

(2) Anything done under arrangements given effect to by that Order is to be treated as done under the arrangements set out in Schedule 1 to this Order.
