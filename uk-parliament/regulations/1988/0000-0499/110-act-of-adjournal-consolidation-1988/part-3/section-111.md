# Act of Adjournal (Consolidation) 1988, section 111

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

## 111. Application of other provisions

The following rules shall apply to an application under rule 107 as they apply to an application under rule 101:—

- rule 102(1) to (3);
- rule 103;
- rule 104(3);
- rule 105;
- rule 106.
