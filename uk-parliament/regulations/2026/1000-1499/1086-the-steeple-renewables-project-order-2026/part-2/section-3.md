# The Steeple Renewables Project Order 2026, section 3

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

## 3. Development consent etc. granted by this Order

(1) Subject to the provisions of this Order and the requirements, the undertaker is granted development consent for the authorised development to be carried out within the Order limits.

(2) Each numbered work must be situated within the corresponding numbered area shown on the works plans.
