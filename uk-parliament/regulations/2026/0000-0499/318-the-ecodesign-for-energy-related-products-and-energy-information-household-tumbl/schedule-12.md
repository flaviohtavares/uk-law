# The Ecodesign for Energy-Related Products and Energy Information (Household Tumble Dryers) Regulations 2026, Schedule 12

## Schedule 12 — Energy efficiency class, acoustic airborne noise emission class, condensation efficiency class and repairability class

*Extent: E+W+S*

Regulations 11(3) and 16(5)

### 1. Energy efficiency class[^key-013842a051dc13c2b69c999c739b41bb]

The energy efficiency class of a household tumble dryer must be determined on the basis of its EEI as set out in Table 6.

Table 6: Energy efficiency class

| Energy efficiency class | EEI |
| --- | --- |
| A (most efficient) | EEI ≤ 43 |
| B | 43 \< EEI ≤ 50 |
| C | 50 \< EEI ≤ 60 |
| D | 60 \< EEI ≤ 70 |
| E | 70 \< EEI ≤ 85 |
| F | 85 \< EEI ≤ 100 |
| G (least efficient) | EEI > 100 |

### 2. Airborne noise emission class[^key-44c6116dab0cc93eb863e037bd70518f]

The acoustic airborne noise emission of a household tumble dryer must be determined as the weighted average value (L<sub>WA</sub>) of the sound power in the eco programme at full load during the drying cycle expressed in dB(A) and rounded to the nearest integer.

**3.**[^key-17d636e0b54fc78a05ad455abb5b1e70] The acoustic airborne noise emission class must be determined on the basis of the L<sub>WA</sub> as set out in Table 7.

Table 7: Acoustic airborne noise emission class

| Acoustic airborne noise emission class | Noise (dB(A)) |
| --- | --- |
| A | L<sub>WA</sub> ≤ 60 |
| B | 60 \< L<sub>WA </sub>≤ 64 |
| C | 64 \< L<sub>WA</sub> ≤ 68 |
| D | L<sub>WA</sub> > 68 |

### 4. Condensation efficiency class[^key-00d3f83c3ba2116a07ff87395201c069]

The condensation efficiency class must be determined on the basis of the weighted condensation efficiency as set out in Table 8.

Table 8: Condensation efficiency class

| Condensation efficiency class | Weighted condensation efficiency (Ct) |
| --- | --- |
| A | Ct ≥ 94 |
| B | 88 ≤ Ct \< 94 |
| C | 82 ≤ Ct \< 88 |
| D | Ct \< 82 |

### 5. Repairability class[^key-98c6343d8e4f85bd576f4d7e96a5e7d2]

The repairability class of a household tumble dryer must be determined on the basis of the repairability index as set out in Table 9.

Table 9: Repairability classes

| Repairability class | Repairability index (R) |
| --- | --- |
| A (most repairable) | R > 9 |
| B | 7 ≤ R ≤ 9 |
| C | 5 ≤ R \< 7 |
| D | 3 ≤ R \< 5 |
| E (least repairable) | R \< 3 |
