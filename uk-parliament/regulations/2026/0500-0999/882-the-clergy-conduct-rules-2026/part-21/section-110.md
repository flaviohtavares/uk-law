# The Clergy Conduct Rules 2026, section 110

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

## 110. Copy of order made on an application

(1) This rule applies if an order is made on an application under [the CCM](https://www.legislation.gov.uk/ukcm/2026/1/contents) or these Rules.

(2) A copy of the order must be given to —

- (a) the parties to the complaint to which the order relates, and
- (b) the other persons (if any) specified in the order.
