# The Civil Procedure Rules 1998, section 3.14

> **Warning: changes not yet applied to this text (11).** Text as at 2026-10-26. See https://www.legislation.gov.uk/changes/affected/uksi/1998/3132

## 3.14. Failure to file a budget[^c-a0854a3753d8762e6dfee5b8f83fb2f2][^c-4079a04c63c1990c9203ca9a6e2ec5ec]

*Extent: E+W*

Unless the court otherwise orders, any party which fails to file a budget despite being required to do so will be treated as having filed a budget comprising only the applicable court fees.
