# The Church Property Measure 2018 (Commencement) Order 2019

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

2019 No. 97

Ecclesiastical Law, England

The Church Property Measure 2018 (Commencement) Order 2019

Made

23rd January 2019

The Archbishops of Canterbury and York, in exercise of the powers conferred by section 53 of the Church Property Measure 2018[^f00001], makes the following Order:

## 1. Citation and interpretation

(1) This Order may be cited as the Church Property Measure 2018 (Commencement) Order 2019.

(2) In this Order “the Measure” means the Church Property Measure 2018.

## 2. Commencement on 1st March 2019

The Measure so far as not already in force, except for sections 12(5) and 36(2), comes into force on 1st March 2019.

\+Justin Cantuar:

Arcbishop of Canterbury

\+Sentamu Ebor:

Archbishop of York

23rd January 2019

EXPLANATORY NOTE

(This note is not part of the Order)

This Order brings into force the substantive provisions of the Church Property Measure 2018.

Sections 53 to 55 came into force on Royal Assent. The remaining provisions of the Measure are brought into force on 1st March 2019.
