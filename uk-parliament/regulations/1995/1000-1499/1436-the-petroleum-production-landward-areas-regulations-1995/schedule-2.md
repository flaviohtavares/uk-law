# The Petroleum (Production) (Landward Areas) Regulations 1995, SCHEDULE 2

> Text as at 2024-01-11.
>
> Extent: England, Wales, Scotland, Northern Ireland.

## SCHEDULE 2 (affected by repeal, see note) — INFORMATION TO BE INCLUDED IN AN APPLICATION FOR A PETROLEUM EXPLORATION AND DEVELOPMENT LICENCE AND SUPPORTING DOCUMENTATION (affected by repeal, see note)[^key-cd3b46a11fde6ac5710a965753364bb2][^key-cd3b46a11fde6ac5710a965753364bb2]

*Extent: E+W+S+N.I.*

Regulation 6(1) *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]

**1.**[^key-5e284821f3dac6551308ef33dd3df329] Name of each applicant in full *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]**(A)**.

**2.**[^key-815c66e2b8094880a32e086317653b54] If the application is made by more than one person *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]**(B)**, and the applicants have agreed on the manner in which the benefits resulting from the exploitation of the licence should be shared between them, the share each applicant would be entitled to take. *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]

**3.**[^key-db45d8396b233a842ac357508cf7ae57] Name of proposed operator. *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]

**4.**[^key-91ce53615985c2535ea6c5da039d5cb9] The reference number of each block in respect of which the application is made and, if the application is made by tender, the consideration by way of initial payment which the applicant is prepared to offer for each such block *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]**(C)**.

**5.**[^key-2ff7cbc6fd03863fe3c8ed7c3752fc1a] An analysis of the geology of the area to which the application relates, identifying, in particular, petroleum prospects. *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]

**6.**[^key-b322e4c1cb55c859feca0555dd3f6c6f] The technical data on which the analysis is based. *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]

**7.**[^key-ae97d1fcb9d0ca7e4976eb6ace49307f] The work programme for evaluating the potential petroleum production from the area to which the application relates which the applicant would be prepared to undertake under the licence applied for. *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]

**8.**[^key-a628444ccb1e3bc144c4ab0628d8bf41] Evidence of the applicant’s technical and financial capacity to undertake that work programme, including the number of staff the applicant intends to assign for that purpose and any relevant technical qualifications held by those staff. *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]

**9.**[^key-0907f4a0e3bb14efd3b2f55d58dffeb0] An explanation of the way in which the work programme takes account of the analysis of the geology. *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]

**10.**[^key-b226ee3013c410574fbc12ddf0db3dc1] In respect of each applicant who is an individual— *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]

- (a) usual residential address; *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
- (b) nationality. *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]

**11.**[^key-be17d0a3f796eba7db79b2d0fc3be1a4] In respect of each applicant which is a body corporate *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]**(D)**—

- (a) place of incorporation; *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
- (b) principal place of business; *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
- (c) in the case of a company, its registered office; *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
- (d) place from which the applicant’s operations under the licence will be directed and controlled; *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
- (e) place from which any commercial activities in connection with the licence will be directed and controlled; *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
- (f) particulars of each member of the board of directors or other governing body of the body corporate, as follows— *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
  - (i) full name *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
  - (ii (affected by repeal, see note))[^key-cd3b46a11fde6ac5710a965753364bb2] usual residential address *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
  - (iii (affected by repeal, see note))[^key-cd3b46a11fde6ac5710a965753364bb2] nationality *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
- (g) where the applicant is or has a subsidiary (as defined in section 736 of the Companies Act 1985), a diagram identifying any companies of which it is a subsidiary and any subsidiaries it has; *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
- (h) the training provided in the three year period ending on the date of the application for the licence for the technical staff whom the applicant expects to employ in connection with the exploration for and production of petroleum from the licensed area; *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
- (i) particulars of capital authorised and issued as follows:— *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
  - (i) class of capital *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
  - (ii (affected by repeal, see note))[^key-cd3b46a11fde6ac5710a965753364bb2] amount authorised *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
  - (iii (affected by repeal, see note))[^key-cd3b46a11fde6ac5710a965753364bb2] amount issued *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
  - (iv (affected by repeal, see note))[^key-cd3b46a11fde6ac5710a965753364bb2] voting rights of each class *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]**(E)**
- (j) particulars of all holdings of not less than 5 per cent in number or value of any class of capital which has been issued by the body corporate as follows:— *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
  - (i) name of holder or names of joint holders, in full (ii)nationality of holder(s) *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
  - (iii (affected by repeal, see note))[^key-cd3b46a11fde6ac5710a965753364bb2] class of holding (iv)amount *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
- (k) particulars of all capital issued to bearer, as follows:— *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
  - (i) class of capital *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
  - (ii (affected by repeal, see note))[^key-cd3b46a11fde6ac5710a965753364bb2] total amount issued *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
  - (iii (affected by repeal, see note))[^key-cd3b46a11fde6ac5710a965753364bb2] amount issued to bearer *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]

**12.**[^key-0e163c66becd1d765cd202df6551f0b8] Details of the fees which accompany the application. *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]

*Notes *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]*

- (1) If there is more than one applicant all the information relating to each applicant which is required should be grouped together in the order in which the applicants are named in paragraph 2. *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
- (2) Where there is more than one signature, the applicant to which each signature relates should be identified. *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
- (3) If the application specifies more than one block it may indicate an order of preference for some or all of the blocks and it may indicate that blocks are applied for as alternatives. *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
- (4) If the body corporate does not possess a capital structure, any comparable information concerning the items listed should be furnished. *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
- (5) The voting rights of each class need not be produced if a copy of the memorandum and articles of association, or other document setting out or defining the constitution, of the body corporate accompanies the application. *(affected by repeal, see note)*[^key-cd3b46a11fde6ac5710a965753364bb2]
