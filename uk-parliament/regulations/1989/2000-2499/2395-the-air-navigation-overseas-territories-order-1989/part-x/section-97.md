# The Air Navigation (Overseas Territories) Order 1989, section 97

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

## 97. Application of Order

The provisions of this Order apply to the territories mentioned in Schedule 16 to this Order, any one of which is in this Order referred to in the expression “the Territory”.
