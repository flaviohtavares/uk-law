# The Land Registration (Amendment) Rules 2008, section 3

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

## 3. Interpretation

In these rules “the principal rules” means the Land Registration Rules 2003[^f00005] and in rule 6 and in the Schedules to these rules (other than in respect of the reference note at the head of each Schedule) a reference to a rule by number is a reference to the rule so numbered in the principal rules.
