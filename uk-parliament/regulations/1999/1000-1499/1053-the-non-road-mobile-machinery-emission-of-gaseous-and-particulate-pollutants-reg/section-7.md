# The Non-Road Mobile Machinery (Emission of Gaseous and Particulate Pollutants) Regulations 1999, section 7

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

**7.** The conformity procedures are set out in regulation 11 and the basic requirements are that once a type approval has been issued, the manufacturer must affix to each engine unit the markings defined in paragraph 3 of Schedule 1 which includes the type approval number. Furthermore where the type approval incorporates restrictions on use, these should be specified in a document accompanying the engine unit and indicating any conditions for fitting. Where a series of engine type is involved there is provision for only one such document to be provided. This information should be delivered to the manufacturer of machinery no later than when the first such engine is despatched.
