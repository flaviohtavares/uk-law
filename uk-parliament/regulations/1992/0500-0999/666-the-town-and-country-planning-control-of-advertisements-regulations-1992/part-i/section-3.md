## 3 (Extent: E) (affected by repeal, see note). Application (Extent: E) (affected by repeal, see note)[^key-b377fef111c3f44259e21d0c1a368060][^key-b8be3ef55c3def2035f5d0777ee2365b][^key-b8be3ef55c3def2035f5d0777ee2365b]

*Extent: E+W*

(1 (Extent: E) (affected by repeal, see note))[^key-b8be3ef55c3def2035f5d0777ee2365b] These Regulations apply to the display on any site in England and Wales of any advertisement. *(Extent: E)* *(affected by repeal, see note)*[^key-b8be3ef55c3def2035f5d0777ee2365b]

(2 (Extent: E) (affected by repeal, see note))[^key-b8be3ef55c3def2035f5d0777ee2365b] Parts II and *(Extent: E)* *(affected by repeal, see note)*[^key-b8be3ef55c3def2035f5d0777ee2365b] III *(Extent: E)* *(affected by repeal, see note)*[^key-b8be3ef55c3def2035f5d0777ee2365b] of these Regulations do not apply to any advertisement falling within a description set out in Schedule 2 provided it complies with any conditions and limitations specified in that Schedule; and— *(Extent: E)* *(affected by repeal, see note)*[^key-b8be3ef55c3def2035f5d0777ee2365b]

- (a (Extent: E) (affected by repeal, see note))[^key-b8be3ef55c3def2035f5d0777ee2365b] in the case of an advertisement falling within Class G, it complies with the standard conditions set out in paragraphs 1, 2, 3, and 5 of Schedule 1; or *(Extent: E)* *(affected by repeal, see note)*[^key-b8be3ef55c3def2035f5d0777ee2365b]
- (b (Extent: E) (affected by repeal, see note))[^key-b8be3ef55c3def2035f5d0777ee2365b] in any other case, it complies with all the standard conditions. *(Extent: E)* *(affected by repeal, see note)*[^key-b8be3ef55c3def2035f5d0777ee2365b]
