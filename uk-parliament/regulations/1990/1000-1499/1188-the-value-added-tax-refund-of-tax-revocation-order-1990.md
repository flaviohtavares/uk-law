# The Value Added Tax (Refund of Tax) (Revocation) Order 1990

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

1990 No. 1188

VALUE ADDED TAX

The Value Added Tax (Refund of Tax) (Revocation) Order 1990

Made

5th June 1990

Laid before the House of Commons

8th June 1990

Coming into force

30th June 1990

The Treasury, in exercise of the powers conferred on them by section 20(3) of the Value Added Tax Act 1983[^f00001] and of all other powers enabling them in that behalf, hereby make the following Order:

## 1. Title and commencement

This Order may be cited as the Value Added Tax (Refund of Tax) (Revocation) Order 1990 and shall come into force on 30th June 1990.

## 2. Revocation

The Value Added Tax (Refund of Tax) Order 1973[^f00002] is hereby revoked.

John Taylor

Kenneth Carlisle

Two of the Lords Commissioners of Her Majesty’s Treasury

5th June 1990

(This note is not part of the Order)

This Order revokes the Value Added Tax (Refundof Tax) Order 1973 which specified the Scottish Special Housing Association as a body entitled to a refundof value added tax on supplies to or importations by it if not made for the purpose of business.
