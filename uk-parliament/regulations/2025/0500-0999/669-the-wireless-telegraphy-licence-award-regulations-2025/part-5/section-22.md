# The Wireless Telegraphy (Licence Award) Regulations 2025, section 22

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

## 22. Posted demand number after the end of the first round

(1) After the end of the first principal stage round, OFCOM shall determine the posted demand number for each lot type for each bidder.

(2) The posted demand number for each bidder for each lot type is the number of lots of that type which the bidder bid for in the first principal stage round.
