# The Fishing Vessels (Safety Provisions) Rules 1975, section 83

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

## 83. General requirements for Class C boats

Class C boats carried in any vessel to which these Rules apply shall comply with the requirements of Schedule 7 to these Rules.
