## 22. Cap: base for scheme years[^key-b9270023bf4188a13f6a7c690e80716d]

*Extent: E+W+S+N.I.*

For the purposes of article 20, the base for a scheme year set out in column 1 of table B is the value set out in the corresponding entry in column 2.

Table B

| *Column 1* | *Column 2* |
| --- | --- |
| *Scheme year* | *Base* |
| 2021 | 155,671,581 |
| 2022 | 151,437,134 |
| 2023 | 147,202,686 |
| 2024 | 92,062,882[^key-10262846c42b0a0772f1c19aedc01edf] |
| 2025 | 86,742,014[^key-71b8bf4a04ae5d9c5ce1de4763b1e0d8] |
| 2026 | 80,063,992[^key-49a6a3e9467385139235f9166933a24b] |
| 2027 | 72,317,337[^key-80c2bfbeba1cd4f9a9f3d14387fbe108] |
