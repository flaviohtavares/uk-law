# The Wireless Telegraphy (Licence Award) Regulations 2020, section 70

> Text as at 2021-03-09.
>
> Extent: England, Wales, Scotland, Northern Ireland.

## 70. 3.6 GHz assignment stage bids[^c-51d69058718ad7c646da3f3f2fc03742]

*Extent: E+W+S+N.I.*

(1) In order to bid for a 3.6 GHz assignment stage option, a bidder must, on the assignment stage form, specify an amount in whole thousands of pounds that it is willing to pay, in addition to the total 3.6 GHz base price for that bidder's winning principal stage bids for 3.6 GHz lots, for a licence that authorises the use of the frequencies corresponding to the block of numbered 3.6 GHz lots that is the 3.6 GHz assignment stage option.

(2) A bidder may make no more than one 3.6 GHz assignment stage bid for each 3.6 GHz assignment stage option.

(3) A bidder is not required to make a 3.6 GHz assignment stage bid.

(4) A 3.6 GHz assignment stage bid is a valid 3.6 GHz assignment stage bid if—

- (a) the bid is specified on a valid assignment stage form; and
- (b) the bidder has paid the full sum of the required assignment stage deposit by the deadline specified by OFCOM.

(5) Where a bidder does not make a valid 3.6 GHz assignment stage bid for a 3.6 GHz assignment stage option that bidder will be deemed to have made a valid 3.6 GHz assignment stage bid with a value of zero pounds for that 3.6 GHz assignment stage option.
