# The Hazardous Waste (England and Wales)Regulations 2005, section 3

> Text as at 2026-07-16.
>
> Extent: England, Wales.

## 3. Annex III to the Waste Directive[^c-18bee718f730fe355b3efd843b2c167e]

*Extent: E+W*

A reference in these Regulations to—

- (a) Annex III is a reference to Annex III (properties of waste which render it hazardous) to the Waste Directive[^c-3feba97541e2c089b193f89f425edb22]...;
- (b) hazardous properties is a reference to the properties in Annex III.
