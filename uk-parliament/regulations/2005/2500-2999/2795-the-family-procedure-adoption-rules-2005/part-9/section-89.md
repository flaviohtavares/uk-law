# The Family Procedure (Adoption) Rules 2005, section 89

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

## 89. Time when an application is made

Where an application must be made within a specified time, it is so made if the court receives the application notice within that time.
