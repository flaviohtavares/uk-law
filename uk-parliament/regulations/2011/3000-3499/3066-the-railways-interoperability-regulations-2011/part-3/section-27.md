# The Railways (Interoperability) Regulations 2011, section 27

> Text as at 2020-12-31.
>
> Extent: England, Wales, Scotland, Northern Ireland.

## 27. Duties on operators

*Extent: E+W+S+N.I.*

The operator of any interoperability constituent for which there is an applicable NTSN[^c-5b8f7bf17e05211c95976c3ca7abe517] that is in use on, or is part of, the rail system [^c-36def6d8a948c1259abf912c530860da]... must ensure that it is—

- (a) correctly installed for the purpose for which it is intended to be used;
- (b) not used for any purpose other than the purpose for which it was designed; and
- (c) maintained in effective working order and good repair.
