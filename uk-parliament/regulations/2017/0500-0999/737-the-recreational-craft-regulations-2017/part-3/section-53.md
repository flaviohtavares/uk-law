# The Recreational Craft Regulations 2017, section 53

> **Warning: changes not yet applied to this text (2).** Text as at 2024-10-01. See https://www.legislation.gov.uk/changes/affected/uksi/2017/737
>
> Extent: England, Wales, Scotland; Northern Ireland (the versions of this text differ in extent).

## 53. Declaration of conformity[^c-742edd61ef9f3824f161a582a5b5bc50][^M_E_15033f4f-773d-4faf-8c3a-2bdab86ce1e2][^c-e6720ace87280b9bda70a2ddb6f9d966]

*Extent: E+W+S*

The [^c-89ac08a40db093a7af2cff63fa582a4d]... declaration of conformity for a product must—

- (a) state that the product complies with the essential requirements;
- (b) contain the elements specified in regulations 44 to 47 for the relevant conformity assessment procedure[^c-042147f90203691c6c911066c996b90f] in respect of the product; and
- (c) be set out in accordance with the model structure set out in Schedule 4.

## 53. EU declaration of conformity[^V_NI_2f4b4777-683d-b055-1838-19bcf451785e][^M_E_4fe6c01e-c261-4eb2-8e66-426c36aa08ef]

*Extent: N.I.*

The EU declaration of conformity for a product must—

- (a) state that the product complies with the essential requirements;
- (b) contain the elements specified in regulations 44 to 47 for the relevant conformity assessment in respect of the product; and
- (c) be set out in accordance with the model structure set out in Schedule 4.
