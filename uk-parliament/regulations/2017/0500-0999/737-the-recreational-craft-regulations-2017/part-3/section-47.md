# The Recreational Craft Regulations 2017, section 47

> **Warning: changes not yet applied to this text (2).** Text as at 2024-10-01. See https://www.legislation.gov.uk/changes/affected/uksi/2017/737
>
> Extent: England, Wales, Scotland; Northern Ireland (the versions of this text differ in extent).

## 47. Noise emissions: personal watercraft[^c-06e3c21abb7c4b1e2fdca776c977c15e][^M_E_dbcbc3a4-8e8a-43ad-975f-a2bb63be91a3]

*Extent: E+W+S*

(1) The personal watercraft or engine manufacturer must apply the relevant procedure in paragraphs (2) or (3) as set out in Schedule 15[^c-b86fc9af0c28c57cf4959aebb23f8cec], with regard to noise emissions for—

- (a) personal watercraft and outboard propulsion engines; and
- (b) stern drive propulsion engines with integral exhausts intended for installation on recreational craft.

(2) Where the tests are conducted using the designated[^c-0ff1c30de9d9e896bdb46537e1047f9a] standard for noise measurement, any of the following modules apply—

- (a) Module A1 (internal production control plus supervised product testing);
- (b) Module G (conformity based on unit verification);
- (c) Module H (conformity based on full quality assurance).

(3) Where the tests are conducted without using the designated[^c-543a401aab01f58f308e7502e50a961a] standard for noise measurement, Module G (conformity based on unit verification) applies.

## 47. Noise emissions: personal watercraft[^V_NI_57819558-8291-9a03-da97-2d8e9f8b0a62][^M_E_15b8f464-a37e-45ba-f9bc-b302bd5efc39]

*Extent: N.I.*

(1) The personal watercraft or engine manufacturer must apply the relevant procedure in paragraphs (2) or (3) as set out in Annex II to Decision 768/2008/EC, with regard to noise emissions for—

- (a) personal watercraft and outboard propulsion engines; and
- (b) stern drive propulsion engines with integral exhausts intended for installation on recreational craft.

(2) Where the tests are conducted using the harmonised standard for noise measurement, any of the following modules apply—

- (a) Module A1 (internal production control plus supervised product testing);
- (b) Module G (conformity based on unit verification);
- (c) Module H (conformity based on full quality assurance).

(3) Where the tests are conducted without using the harmonised standard for noise measurement, Module G (conformity based on unit verification) applies.
