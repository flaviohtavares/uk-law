# The Police and Criminal Evidence (Northern Ireland) Order 1989 (Codes of Practice) (Temporary Modification to Code D) Order 2006, section 2

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

## 2. Code of practice

(1) The code of practice for the identification of persons by police officers[^f00002] (“Code D”) issued under Article 65 of the 1989 Order is to be treated as having effect in accordance with the modifications set out in the Schedule to this Order.

(2) The modifications to Code D set out in the Schedule to this Order shall have effect for the period of 1 year beginning with the date on which this Order comes into force.

## Annotations

[^f00002]: Footnote: The Secretary of State is required to issue codes of practice under Article 65(1)(b) of the 1989 Order; the code which is modified as a consequence of this Order was brought into operation by the Police and Criminal Evidence (Northern Ireland) Order 1989 (Codes of Practice)(No. 2) Order 1996 ([S.I. 1996/261](https://www.legislation.gov.uk/uksi/1996/261)).
