# The Foot-and-Mouth Disease (England) Order 2006, section 20A

> Text as at 2023-12-20.
>
> Extent: England, Wales, Scotland.

## 20A. Diagnostic tests[^c-637a4735fc083f43bf8886a69fc385dc]

*Extent: E+W+S*

(1) The national reference laboratory must use the diagnostic tests in the OIE manual which constitute the reference tests for vesicular disease diagnosis.

(2) The use of a test not included in the OIE manual is permitted only when the performance of the test in question demonstrates that it matches or exceeds the sensitivity and specificity parameters set down in—

- (a) the OIE manual; or
- (b) national accreditation standards.
