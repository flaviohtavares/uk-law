# Immigration and Asylum Act 1999, section 33

## 33. Prevention of clandestine entrants: code of practice[^c11432681][^key-43e719491b712f16da2f0fb35361a2be]

*Extent: E+W+S+N.I.*

(1)[^key-2512b12153c1a0d0be0453b85eb4329c] The Secretary of State must issue a code of practice to be followed by any person operating a system for preventing the carriage of clandestine entrants. *(affected by repeal, see note)*[^key-2512b12153c1a0d0be0453b85eb4329c]

(2) Before issuing the code, the Secretary of State must— *(affected by repeal, see note)*[^key-2512b12153c1a0d0be0453b85eb4329c]

- (a) consult such persons as he considers appropriate; and *(affected by repeal, see note)*[^key-2512b12153c1a0d0be0453b85eb4329c]
- (b) lay a draft before *(affected by repeal, see note)*[^key-2512b12153c1a0d0be0453b85eb4329c] both Houses of *(affected by repeal, see note)*[^key-fbb2a5c2cffb169d33c4922f9a8c849b] *(affected by repeal, see note)*[^key-2512b12153c1a0d0be0453b85eb4329c] Parliament. *(affected by repeal, see note)*[^key-2512b12153c1a0d0be0453b85eb4329c]

(3) The requirement of subsection (2)(a) may be satisfied by consultation before the passing of this Act. *(affected by repeal, see note)*[^key-2512b12153c1a0d0be0453b85eb4329c]

(4) After laying the draft code before Parliament, the Secretary of State may bring the code into operation by an order. *(affected by repeal, see note)*[^key-2512b12153c1a0d0be0453b85eb4329c]

(5) The Secretary of State may from time to time revise the whole or any part of the code and issue the code as revised. *(affected by repeal, see note)*[^key-2512b12153c1a0d0be0453b85eb4329c]

(6) Subsections (2) and (4) also apply to any revision, or proposed revision, of the code. *(affected by repeal, see note)*[^key-2512b12153c1a0d0be0453b85eb4329c]
