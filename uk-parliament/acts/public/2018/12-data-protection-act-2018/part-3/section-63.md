# Data Protection Act 2018, section 63

> **Warning: changes not yet applied to this text (7).** Text as at 2026-09-30. See https://www.legislation.gov.uk/changes/affected/ukpga/2018/12
>
> Extent: England, Wales, Scotland, Northern Ireland.

## 63. Co-operation with the Commission[^M_I_3f872866-06d2-4431-ac57-220c7b048d4c][^c-163cfa93d7f3780e660a1d450282fb9d]

*Extent: E+W+S+N.I.*

Each controller and each processor must co-operate, on request, with the Commission in the performance of the Commission's tasks.
