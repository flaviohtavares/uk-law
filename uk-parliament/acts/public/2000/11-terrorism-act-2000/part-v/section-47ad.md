# Terrorism Act 2000, section 47AD

> **Warning: changes not yet applied to this text (28).** Text as at 2026-07-08. See https://www.legislation.gov.uk/changes/affected/ukpga/2000/11
>
> Extent: England, Wales, Scotland, Northern Ireland.

## 47AD. Publication of code[^key-bebeaffb41b606a484ff4eb46c3b1efe]

*Extent: E+W+S+N.I.*

(1) The Secretary of State must publish the code (and any replacement code) issued under section 47AB (2).

(2) The Secretary of State must publish—

- (a) any alteration issued under section 47AB (2), or
- (b) the code or replacement code as altered by it.
