# Criminal Justice and Court Services Act 2000, section 28

> **Warning: changes not yet applied to this text (19).** Text as at 2026-10-01. See https://www.legislation.gov.uk/changes/affected/ukpga/2000/43

## 28. Disqualification from working with children: adults.[^c10578201]

*Extent: E+W+S+N.I.*

(1 (Extent: E+W) (affected by repeal, see note))[^c-d1cbfebd68c6adb7ae43e71db2ef75e6] This section applies where either of the conditions set out below is satisfied in the case of an individual. *(Extent: E+W)* *(affected by repeal, see note)*[^c-d1cbfebd68c6adb7ae43e71db2ef75e6]

(2 (Extent: E+W) (affected by repeal, see note))[^c-d1cbfebd68c6adb7ae43e71db2ef75e6] The first condition is that— *(Extent: E+W)* *(affected by repeal, see note)*[^c-d1cbfebd68c6adb7ae43e71db2ef75e6]

- (a (Extent: E+W) (affected by repeal, see note))[^c-d1cbfebd68c6adb7ae43e71db2ef75e6] the individual is convicted of an offence against a child committed when he was aged 18 or over, and *(Extent: E+W)* *(affected by repeal, see note)*[^c-d1cbfebd68c6adb7ae43e71db2ef75e6]
- (b (Extent: E+W) (affected by repeal, see note))[^c-d1cbfebd68c6adb7ae43e71db2ef75e6] a qualifying sentence is imposed by a *(Extent: E+W)* *(affected by repeal, see note)*[^c-d1cbfebd68c6adb7ae43e71db2ef75e6] superior court[^c-9f8b9a990490d8e5a6b916de86fcc7a3] *(Extent: E+W)* *(affected by repeal, see note)*[^c-d1cbfebd68c6adb7ae43e71db2ef75e6] in respect of the conviction. *(Extent: E+W)* *(affected by repeal, see note)*[^c-d1cbfebd68c6adb7ae43e71db2ef75e6]

(3 (Extent: E+W) (affected by repeal, see note))[^c-d1cbfebd68c6adb7ae43e71db2ef75e6] The second condition is that— *(Extent: E+W)* *(affected by repeal, see note)*[^c-d1cbfebd68c6adb7ae43e71db2ef75e6]

- (a (Extent: E+W) (affected by repeal, see note))[^c-d1cbfebd68c6adb7ae43e71db2ef75e6] the individual is charged with an offence against a child committed when he was aged 18 or over, and *(Extent: E+W)* *(affected by repeal, see note)*[^c-d1cbfebd68c6adb7ae43e71db2ef75e6]
- (b (Extent: E+W) (affected by repeal, see note))[^c-d1cbfebd68c6adb7ae43e71db2ef75e6] a relevant order is made by a *(Extent: E+W)* *(affected by repeal, see note)*[^c-d1cbfebd68c6adb7ae43e71db2ef75e6] superior court[^c-d63f381d2f4a80f423701c76f429a6ea] *(Extent: E+W)* *(affected by repeal, see note)*[^c-d1cbfebd68c6adb7ae43e71db2ef75e6] in respect of the act or omission charged against him as the offence. *(Extent: E+W)* *(affected by repeal, see note)*[^c-d1cbfebd68c6adb7ae43e71db2ef75e6]

(4 (Extent: E+W) (affected by repeal, see note))[^c-d1cbfebd68c6adb7ae43e71db2ef75e6] Subject to subsection (5), the court must order the individual to be disqualified from working with children. *(Extent: E+W)* *(affected by repeal, see note)*[^c-d1cbfebd68c6adb7ae43e71db2ef75e6]

(5 (Extent: E+W) (affected by repeal, see note))[^c-d1cbfebd68c6adb7ae43e71db2ef75e6] An order shall not be made under this section if the court is satisfied, having regard to all the circumstances, that it is unlikely that the individual will commit any further offence against a child. *(Extent: E+W)* *(affected by repeal, see note)*[^c-d1cbfebd68c6adb7ae43e71db2ef75e6]

(6 (Extent: E+W) (affected by repeal, see note))[^c-d1cbfebd68c6adb7ae43e71db2ef75e6] If the court does not make an order under this section, it must state its reasons for not doing so and cause those reasons to be included in the record of the proceedings. *(Extent: E+W)* *(affected by repeal, see note)*[^c-d1cbfebd68c6adb7ae43e71db2ef75e6]
