# Telecommunications Act 1984, section 9

> **Warning: changes not yet applied to this text (3).** Text as at 2026-04-06. See https://www.legislation.gov.uk/changes/affected/ukpga/1984/12
>
> Extent: England, Wales, Scotland, Northern Ireland.

## 9. Public telecommunication systems.

*Extent: E+W+S+N.I.*

(1)[^c19221851] The Secretary of State may by order designate as a public telecommunication system any telecommunication system the running of which is authorised by a licence to which section 8 above applies; and any reference in this Act to a public telecommunication system is a reference to a telecommunication system which is so designed and the running of which is so authorised. *(affected by repeal, see note)*[^c19221851]

(2) An order under subsection (1) above shall not come into operation until after the end of the period of 28 days beginning with— *(affected by repeal, see note)*[^c19221851]

- (a) the day on which copies of the order, and of the licence to which section 8 above applies, are laid before each House of Parliament; or *(affected by repeal, see note)*[^c19221851]
- (b) if such copies are so laid on different days, the last of those days. *(affected by repeal, see note)*[^c19221851]

(3)[^c13617421] In this Act “ *(affected by repeal, see note)*[^c19221851]**public telecommunications operator *(affected by repeal, see note)*[^c19221851]**” means a person authorised by a licence to which section 8 above applies to run a public telecommunication system. *(affected by repeal, see note)*[^c19221851]

(4) In any case where it appears to the Secretary of State that it is expedient for transitional provision to be made in connection with a telecommunication system ceasing to be a public telecommunication system, or a person ceasing to be a public telecommunications operator, the Secretary of State may make a scheme giving effect to such transitional provision as he thinks fit. *(affected by repeal, see note)*[^c19221851]
