# Value Added Tax Act 1983, section 28

> This provision is no longer in force.
>
> Extent: England, Wales, Scotland, Northern Ireland.

## 28. Local authorities.

*Extent: E+W+S+N.I.*

**No longer in force (ended 1994-09-01).**

(1) A local authority which makes taxable supplies is liable to be registered under this Act, whatever the value of the supplies; and accordingly Schedule 1 to this Act shall apply, in a case where the value of the taxable supplies made by a local authority in any period of one year does not exceed the sum for the time being specified in paragraph 1(1)(a)[^c14321181]of that Schedule, as if that value exceeded that sum.

(2) In this section “**local authority**” has the same meaning as in section 20 above.
