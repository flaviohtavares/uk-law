(3 (Extent: E+W) (affected by repeal, see note))[^key-30898360abe68d9ccbf000961635935c] “ *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]**Child *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]**” means a person under 16. *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]

(4 (Extent: E+W) (affected by repeal, see note))[^key-30898360abe68d9ccbf000961635935c] “ *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]**Image *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]**” means an image produced by any means, whether of a real or imaginary subject. *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]

(5 (Extent: E+W) (affected by repeal, see note))[^key-30898360abe68d9ccbf000961635935c] “ *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]**Sexual activity *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]**” means an activity that a reasonable person would, in all the circumstances but regardless of any person’s purpose, consider to be sexual. *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]

(6 (Extent: E+W) (affected by repeal, see note))[^key-30898360abe68d9ccbf000961635935c] A communication is sexual if— *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]

- (a (Extent: E+W) (affected by repeal, see note))[^key-30898360abe68d9ccbf000961635935c] any part of it relates to sexual activity, or *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]
- (b (Extent: E+W) (affected by repeal, see note))[^key-30898360abe68d9ccbf000961635935c] a reasonable person would, in all the circumstances but regardless of any person’s purpose, consider that any part of the communication is sexual. *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]

(7 (Extent: E+W) (affected by repeal, see note))[^key-30898360abe68d9ccbf000961635935c] An image is sexual if— *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]

- (a (Extent: E+W) (affected by repeal, see note))[^key-30898360abe68d9ccbf000961635935c] any part of it relates to sexual activity, or *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]
- (b (Extent: E+W) (affected by repeal, see note))[^key-30898360abe68d9ccbf000961635935c] a reasonable person would, in all the circumstances but regardless of any person’s purpose, consider that any part of the image is sexual. *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]
