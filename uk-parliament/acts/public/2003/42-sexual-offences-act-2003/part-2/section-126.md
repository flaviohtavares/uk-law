## 126 (Extent: E+W) (affected by repeal, see note). Interim RSHOs (Extent: E+W) (affected by repeal, see note)[^key-30898360abe68d9ccbf000961635935c][^key-30898360abe68d9ccbf000961635935c]

*Extent: N.I.*

(1 (Extent: E+W) (affected by repeal, see note))[^key-30898360abe68d9ccbf000961635935c] This section applies where an application for a risk of sexual harm order (“ *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]**the main application *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]**”) has not been determined. *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]

(2 (Extent: E+W) (affected by repeal, see note))[^key-30898360abe68d9ccbf000961635935c] An application for an order under this section (“an interim risk of sexual harm order”)— *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]

- (a (Extent: E+W) (affected by repeal, see note))[^key-30898360abe68d9ccbf000961635935c] may be made by the complaint by which the main application is made, or *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]
- (b (Extent: E+W) (affected by repeal, see note))[^key-30898360abe68d9ccbf000961635935c] if the main application has been made, may be made by *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c] the Chief Constable of the Police Service of Northern Ireland[^key-124909d06fedcb0e5837a1d387261611] *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c], by complaint to the court to which that application has been made. *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]

(3 (Extent: E+W) (affected by repeal, see note))[^key-30898360abe68d9ccbf000961635935c] The court may, if it considers it just to do so, make an interim risk of sexual harm order, prohibiting the defendant from doing anything described in the order. *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]

(4 (Extent: E+W) (affected by repeal, see note))[^key-30898360abe68d9ccbf000961635935c] Such an order— *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]

- (a (Extent: E+W) (affected by repeal, see note))[^key-30898360abe68d9ccbf000961635935c] has effect only for a fixed period, specified in the order; *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]
- (b (Extent: E+W) (affected by repeal, see note))[^key-30898360abe68d9ccbf000961635935c] ceases to have effect, if it has not already done so, on the determination of the main application. *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]

(5 (Extent: E+W) (affected by repeal, see note))[^key-30898360abe68d9ccbf000961635935c] The applicant or the defendant may by complaint apply to the court that made the interim risk of sexual harm order for the order to be varied, renewed or discharged. *(Extent: E+W)* *(affected by repeal, see note)*[^key-30898360abe68d9ccbf000961635935c]
