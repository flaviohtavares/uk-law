# The Hazardous Waste (Wales) Regulations 2005, section 3

> Text as at 2024-01-01.
>
> Extent: England, Wales.

## 3. Annex III to the Waste Directive[^c-658a96cff6f0883ed6c410d144445adc]

*Extent: E+W*

A reference in these Regulations to—

- (a) Annex III is a reference to Annex III (properties of waste which render it hazardous) to the Waste Directive[^c-7d9a10c8292930ded73cdd68d9b2da68]...;
- (b) hazardous properties is a reference to the properties in Annex III.
