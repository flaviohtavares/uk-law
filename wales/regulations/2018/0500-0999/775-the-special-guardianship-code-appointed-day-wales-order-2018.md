# The Special Guardianship Code (Appointed Day) (Wales) Order 2018

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

2018 No. 775 (W. 157)

Social Care, Wales

The Special Guardianship Code (Appointed Day) (Wales) Order 2018

Made

27 June 2018

The Welsh Ministers, in exercise of the powers conferred by section 146(4)(b) of the Social Services and Well-being (Wales) Act 2014[^f00001], make the following Order:

## 1. Title and application

(1) The title of this Order is the Special Guardianship Code (Appointed Day) (Wales) Order 2018.

(2) This Order applies in relation to Wales.

## 2. Appointed Day

The day appointed for the coming into force of the code of practice on the exercise of social services functions in relation to special guardianship orders is 2 July 2018[^f00002].

Huw Irranca-Davies

Minister for Children, Older People and Social Care, under authority of the Cabinet Secretary for Health and Social Services, one of the Welsh Ministers

27 June 2018

EXPLANATORY NOTE

(This note is not part of the Order)

This Order appoints 2 July 2018 as the day on which the code of practice on the exercise of social services functions in relation to special guardianship orders comes into force. This code was issued by the Welsh Ministers under section 145(1) of the Social Services and Well-being (Wales) Act 2014 (“the 2014 Act”) on 29 June 2018.

The code imposes requirements and includes guidelines setting out aims, objectives and other matters in relation to the exercise of special guardianship functions by a local authority.

Section 145(3) of the 2014 Act requires local authorities to act in accordance with any relevant requirements contained in a code issued under section 145(1) and to have regard to any relevant guidelines contained in it.

The code is available on the Welsh Government website, gov.wales.
