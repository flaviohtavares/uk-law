# The Welsh Language (Wales) Measure 2011 (Commencement No.3) Order 2012

> This is the text as originally enacted or made. It may have been changed since; check legislation.gov.uk for the current version.

2012 No. 223 (W. 37) (C. 7)

WELSH LANGUAGE, WALES

The Welsh Language (Wales) Measure 2011 (Commencement No.3) Order 2012

Made

30 January 2012

The Welsh Ministers, in exercise of the power conferred by section 156(2) of the Welsh Language (Wales) Measure 2011[^f00001], make the following Order:

## 1. Title

The title of this Order is the Welsh Language (Wales) Measure 2011 (Commencement No.3) Order 2012.

## 2. Commencement

The following provisions of the Welsh Language (Wales) Measure 2011 come into force on 5 February 2012—

- (a) section 148;
- (b) section 149.

Leighton Andrews

Minister for Education and Skills, one of the Welsh Ministers

30 January 2012

(This note is not part of the Order)

This Order is made under section 156(2) of the Welsh Language (Wales) Measure 2011 (“the Measure”) and brings into force certain provisions of the Measure. These provisions relate to the Welsh Ministers' Welsh language strategy and the establishment of the Welsh Language Partnership Council.

(This note is not part of the Order)
