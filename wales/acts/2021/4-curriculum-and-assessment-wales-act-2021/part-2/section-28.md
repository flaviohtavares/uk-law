# Curriculum and Assessment (Wales) Act 2021, section 28

> **Warning: changes not yet applied to this text (2).** Text as at 2026-09-01. See https://www.legislation.gov.uk/changes/affected/asc/2021/4
>
> Extent: England, Wales.

## 28. General implementation requirements[^c-ccf9c6f7c21cee52261e9deb236fa3bb][^c-ee87d7e1c648445aaa2bef4bb77152d9][^c-c69817860d8596d3d0cb0bb86b053271][^c-a9746c3f8bd0274f19767c140677009c][^c-438e2dfab6ea23640852cebbf4b805bb]

*Extent: E+W*

The adopted curriculum must be implemented in a way that—

- (a) enables each pupil to develop in the ways described in the four purposes,
- (b) secures teaching and learning that offers appropriate progression for each pupil,
- (c) is suitable for each pupil's age, ability and aptitude,
- (d) takes account of each pupil's additional learning needs (if any), and
- (e) secures broad and balanced teaching and learning for each pupil.
